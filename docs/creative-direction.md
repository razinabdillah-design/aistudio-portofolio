# RAZIN PORTFOLIO — CREATIVE DIRECTION

## DESIGN POSITIONING

The website must feel:
- **Editorial**
- **Personal**
- **Technical**
- **Experimental**
- **Human**
- **Intentional**
- **Curious**

It must **NOT** feel like:
- a SaaS landing page
- an AI-generated portfolio template
- a dashboard
- a startup website
- a developer-template showcase
- a cyberpunk interface
- a generic bento-grid portfolio

---

## CORE IDEA

This website represents a person moving through:
- **projects**
- **professional environments**
- **international experiences**
- **organizations**
- **systems**
- **people**
- **future exploration**

The visual language should therefore feel like a **JOURNEY** rather than a database.

---

## ANTI-AI LAYOUT RULES

Avoid repeatedly using:
- eyebrow
- headline
- paragraph
- three cards

Avoid:
- three equal cards
- four equal cards
- uniform grids everywhere
- identical section compositions
- repeated rounded containers
- repeated badge systems
- repeated icon + title + paragraph cards

**Rule:** Never solve every section using a grid.

---

## ASYMMETRY

Actively use intentional asymmetry.

Possible compositions:
- **65 / 35**
- **40 / 60**
- large object + small annotation
- offset typography
- cropped text
- overlapping layers
- unexpected whitespace
- staggered content positions
- mixed media scales

**Rule:** Do not force symmetry when it reduces personality.

---

## TYPOGRAPHY AS VISUAL MATERIAL

Typography is not only for headings.

Use selected large editorial typography as composition.

Allow:
- oversized words
- line breaks with intent
- cropped typography
- offset alignment
- text crossing columns
- small technical annotations
- large statements contrasted with tiny metadata

**Constraint:** Maintain accessibility and readability.

---

## CARD BUDGET

Cards must be used only when content genuinely requires containment.

**Target:**
Remove approximately **50% of unnecessary bordered card containers** compared with conventional AI portfolio layouts.

Prefer:
- open layout
- whitespace
- rules
- typography
- images
- artifacts
- lines
- annotations

---

## SECTION DIFFERENTIATION

Every major Home chapter must have a different visual behavior.

- **Projects:** technical / artifact-driven
- **Work Experience:** documentary / professional
- **International:** photographic / spatial
- **Organizations:** human / network-oriented
- **Committee:** operational / energetic
- **Systems:** diagrammatic / transformation
- **Still Exploring:** open / unfinished / forward-looking

**Rule:** Never reuse one visual grammar for all sections.

---

## COLOR PHILOSOPHY

### Base:
- `#F3F1EB` (Warm Canvas)
- `#15181D` (Deep Ink)

### Primary:
- `#3157D5` (Cobalt Accent)

### Supporting Palette:
- `#7696E8` (Technical Blue)
- `#C98259` (Restrained Warm Coral / Ochre)
- `#718878` (Muted Botanical Green)

**Rules:**
- Do not use colors as category labels.
- Use color as atmosphere.
- Different sections may temporarily shift visual atmosphere while remaining part of the same brand.
- Avoid rainbow UI.
- Avoid excessive gradients.
- Avoid neon cyberpunk.

---

## COLOR TERRITORIES

- **Projects:** warm canvas + cobalt + technical blue
- **Professional:** cream + ink + restrained coral
- **International:** sunlit warm tones + blue
- **Community:** cream + muted green + cobalt
- **Systems:** dark ink + blue + off-white
- **Exploration:** dark atmospheric base with restrained accent transitions

---

## MOTION PHILOSOPHY

Motion must communicate:
- hierarchy
- continuity
- relationship
- transformation
- state

**Rule:** Motion must **NOT** exist merely to show that something can move.

Use four motion families:
1. **Narrative Motion**
2. **Spatial Motion**
3. **Responsive Motion**
4. **Ambient Motion**

---

## MOTION BUDGET

Per viewport:
- **Maximum one dominant motion idea**
- **Plus one or two subtle supporting interactions**

Avoid combining simultaneously:
- particles
- glow
- parallax
- cursor effects
- text morphing
- animated backgrounds
- floating cards

**Principle:** Motion should feel designed rather than accumulated.

---

## JOURNEY LINE

Use a recurring **Journey Line** motif.

It may behave differently:
- **Hero:** trajectory
- **Projects:** technical connector
- **Professional Experience:** transition
- **International:** route
- **Organizations:** network
- **Systems:** flow
- **Exploration:** line continuing beyond the page

**Rule:** The Journey Line must remain subtle and secondary.

---

## TECHNICAL LANGUAGE

Use engineering/documentary UI language selectively.

- Technical styling is strongest in: **Projects**, **Systems**, **Project detail**.
- It should be lighter in: **International**, **Journey**, **Organizations**, **About**, **Professional Experience**.
- Avoid repetitive: `ARTIFACT`, `VERIFIED`, `EVIDENCE`, `SPEC`, `SYSTEM VERSION` unless genuinely meaningful.

---

## MEDIA

- Real media will be added later.
- For now, use intentional media placeholders.
- **Never** use stock photography to simulate Razin's real experiences.
- **Do not** generate fake personal photographs.
- Placeholders should preserve final composition and aspect ratio.

---

## CREATIVE COMPONENT POLICY

External UI libraries are references and component sources, not design systems.

Possible sources:
- React Bits
- Motion Primitives
- Aceternity UI

**Rules:**
- Use at most **one significant external interaction concept per section**.
- Every imported concept must be adapted to:
  - Razin typography
  - Razin colors
  - Razin spacing
  - Razin content
  - Razin motion grammar
- **Never** make the website look like the source library demo.

---

## PERFORMANCE

Creative design must **not** depend on:
- heavy 3D scenes
- continuous canvas rendering
- large particle simulations
- large shader backgrounds
- scroll hijacking

Prefer:
- `transform`
- `opacity`
- `clip-path`
- SVG
- CSS
- Motion for React (`motion/react`)

---

## RESPONSIVE DESIGN

- Desktop may be expressive.
- Mobile must become simpler.
- Mobile does not need to reproduce every desktop visual behavior.
- Remove unnecessary sticky effects, hover interactions, and complex spatial animation on small screens.

---

## FINAL TEST

Before accepting any major visual section, ask:

1. **Could this exact section appear in hundreds of AI-generated portfolio websites?**  
   *If YES: redesign it.*

2. **Could the section still be recognized as part of Razin's visual system without seeing his name?**  
   *If NO: strengthen its identity.*
